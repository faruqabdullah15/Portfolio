# Personal Portfolio

A responsive personal portfolio built with **Next.js** and **Framer Motion** — smooth scroll animations, modern dark theme, and mobile-first layout.

**Live site:** [https://portfolio-faruqabdullah.vercel.app](https://portfolio-faruqabdullah.vercel.app)

## Sections

- Hero with name, alias logo, and social links
- About & interests
- Educational qualifications
- Work experience
- Expertise (domains, tech stack, tools)
- Featured projects with links
- Extracurricular activities & social work
- Contact / get connected

## Customize Your Content

Edit `src/data/portfolio.ts` with your real information, then redeploy.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Deployed on [Vercel](https://vercel.com). After logging in once (`npx vercel login`), redeploy with:

```bash
npm run deploy
```
